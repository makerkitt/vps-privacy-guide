## 每台 VPS 部署后的清单

### 基础状态

- [ ] SSH 密钥可用，实际登录端口没有被防火墙阻断。
- [ ] 镜像版本和摘要与版本清单匹配。
- [ ] 状态目录和密钥权限正确，数据库持久化。
- [ ] 2095/2096 仅回环映射；从外部不能直接访问面板。
- [ ] 管理员初始密码已修改，实际凭据没有进入 Git。
- [ ] TCP 443、TCP 8443、UDP 443 正确映射并在云安全组放行。

### 三协议

- [ ] Reality：客户端完成认证、访问受控 HTTPS 测试站点、出口符合预期。
- [ ] AnyTLS：证书验证开启，身份和有效期正确，请求成功。
- [ ] Hysteria2：从实际使用网络完成 QUIC 握手和请求；UDP 转发需求另测。
- [ ] 每种协议都用错误凭据验证拒绝访问。
- [ ] 每条节点单独测试，没有被客户端自动切换掩盖失败。
- [ ] 若启用 TUN/分流，额外检查 DNS、WebRTC、局域网和国内网站路径。

### IP 防泄露

按 [详细测试方法](leak-protection.md) 执行，记录客户端版本和测试网络。

- [ ] 明确受保护流量与允许直连的范围，并保存本地公网地址作为私有对照。
- [ ] 受保护的 IPv4/IPv6 流量按预期代理或阻断，没有意外直连。
- [ ] DNS 路径符合配置，没有意外回落到本地运营商解析。
- [ ] WebRTC/UDP 不暴露本地公网 IP。
- [ ] 节点不可达和客户端退出时，受保护流量不能自动直连。
- [ ] 切网、休眠唤醒和重启后重复检查上述项目。

### 生命周期

- [ ] 容器重建后用户、TLS、节点仍保留。
- [ ] 备份可以在独立测试目录恢复，升级回滚过程已演练。
- [ ] 证书自动续期、同步到容器、服务加载分别验证。
- [ ] 订阅重新下载后节点地址、认证信息、TLS 参数仍正确。
