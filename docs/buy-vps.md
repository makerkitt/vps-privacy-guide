## 已有 VPS 也能开始

教程不依赖搬瓦工专有功能。已有服务器满足下列条件即可，不需要为了跟教程再买一台。

| 项目 | 需要确认 |
| --- | --- |
| 系统 | 例如 Ubuntu 24.04；能够安装受支持的 Docker Engine 和 Compose v2 |
| 管理权限 | 可以 SSH 登录，并具备 sudo 或 root 权限 |
| 公网地址 | 主路径使用独立公网 IPv4；IP 证书需要能证明控制该 IP |
| 网络 | TCP 443、8443 和 UDP 443 可用；Hysteria2 必须实测 UDP |
| 流量 | 看清月流量、限速与超额处理，不只看端口峰值带宽 |
| 机房与线路 | 按实际所在地和运营商测试；同一机房对不同网络可能表现不同 |
| 证书 | 有域名可用域名证书；无域名可选择 IP 证书并配置自动续期 |

首次验证优先用新安装、没有其他业务的 VPS，便于对照教程复现。不要为了换系统直接重装承载其他业务的机器。

## 开通后记录

将 IP、SSH 用户和端口、密钥文件位置保存到自己的密码管理器或私有运维文件。给 AI 的连接信息优先使用 SSH 别名，例如 `my-vps`，不要把初始密码或私钥粘贴到公开仓库或 Issue。

如果只有初始密码，先在自己的终端登录并设置密钥；确认另一终端能用密钥登录后，再调整密码登录策略。
