VPS 就是一台放在机房里的电脑。你把代理服务装在上面，手机和电脑连过去，再由它访问网站。

## 先看线路，再看配置

对这类用途来说，服务器到你所在网络的线路很重要。同一台服务器，在家里宽带上和手机流量上的表现可能不同。不要只看“几核 CPU”和“多大带宽”，还要看机房位置、月流量，以及流量用完后怎么处理。

这份教程还没有完成真实线路测试，所以暂时不指定某个套餐，也不承诺买了哪台就一定快。能测试线路的话，尽量用你以后常用的网络来测。

## 开通时选什么

系统按 **Ubuntu 24.04** 准备，后面的部署步骤会容易对照。服务器需要独立公网 IPv4，并且能通过 SSH 登录、安装软件。

另外确认服务商允许使用 UDP。我们准备的 Hysteria2 节点需要它；另外两种连接方式使用 TCP。防火墙怎么放行，等部署时再一步步设置。

域名现在不用急着买。教程也提供 IP 证书的做法，有服务器 IP 就可以继续准备。

如果你已有一台装了网站或其他服务的 VPS，先检查再动手。不要为了跟着教程操作，就直接把它重装了。

## 开通后，把这几样记下来

- **服务器 IP**：一般在服务商后台能看到。
- **SSH 用户名和端口**：有些机器是 root 和 22，有些不是，按后台提供的填写。
- **登录方式**：初始密码，或者下载到电脑上的密钥文件。

这些信息留在自己的电脑上就好。密码和私钥不要上传到仓库，也不要贴进 Issue。

如果服务商给的是密码，可以先在自己的终端登录，再配置密钥登录。等你确认新开的另一个终端也能用密钥连上，再关闭密码登录，免得把自己锁在外面。

准备好了，就去 [把服务器配起来](deployment.md)。
